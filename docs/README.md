# 项目文档索引

第一次了解项目从 [根 README](../README.md) 开始。Agent 按任务读取相关源码与文档章节，不要求每次全文加载所有资料。

当前进度只在 PROJECT_STATUS 维护，运行细节在前端 README，Agent 行为与上下文路由在 AGENTS；正式设计资料保留毕业设计与答辩所需的完整性。历史材料不替代当前规范或实现状态。

## 当前开发入口

| 文档 | 职责 | 什么时候读 |
|---|---|---|
| [README.md](../README.md) | 项目介绍、技术栈概览与一级入口 | GitHub 初次访问或了解项目定位 |
| [AGENTS.md](../AGENTS.md) | Agent 行为约束、开发边界与上下文路由 | 在仓库执行任务时 |
| [PROJECT_STATUS.md](../PROJECT_STATUS.md) | 当前能力、近期下一步、已知限制与当前验证 | 继续任务、核对完成度或更新进度 |
| [frontend/README.md](../frontend/README.md) | 开发命令、工具配置、Mock 开关、请求链与部署；本地后端启动和测试入口 | 安装、运行、验证或部署 |
| [DESIGN.md](../DESIGN.md) | UI Token、视觉、组件与动效规范 | UI 对应主题；已有页面以 HTML 为视觉基准 |
| [HTML 原型](../html/) / [Vue 源码](../frontend/src/) | 页面视觉事实 / 当前实现 | 页面迁移、同视口对照或源码问题 |
