# 项目文档索引

第一次了解项目从 [根 README](../README.md) 开始。Agent 按任务读取相关源码与文档章节，不要求每次全文加载所有资料。

本项目采用简单、够用、作者能解释和维护的毕业设计基线。Agent行为由AGENTS约束，长期工程规则由开发规范维护；不为追求极端覆盖或企业级复杂度扩大需求。

当前进度只在PROJECT_STATUS维护，运行细节在前端README。正式需求可以先于代码调整；当前接口仍按API的真实实现标识描述，基线与实现之间的待调整差距写入PROJECT_STATUS。历史材料不替代当前规范或实现状态。
