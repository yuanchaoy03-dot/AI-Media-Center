# 《基于大语言模型的个人智能影音平台设计与实现》API 接口文档

本文依据当前实现与 [API 契约](API.md)整理，核对日期为 2026-10-11，用于接口调用、联调和排版评估，不替代正式 API 契约。

本文收录 3 个业务模块、12 个已实现接口。`implemented` 表示已实现、可以调用；`confirmed` 表示契约已确认但不代表已实现；`draft` 表示草案。下列接口均为 `implemented`，不收录尚未实现的电影刮削、个人片库、AI/RAG、推荐、播放及开发 Mock 接口。

## 接口通用说明

- 开发环境服务地址：`http://127.0.0.1:8080`，接口前缀为 `/api`。下文路径均已包含该前缀；部署后使用实际服务地址。
- JSON 请求使用 `Content-Type: application/json`，响应使用 `application/json`，建议发送 `Accept: application/json`。字段名采用 camelCase。
- 仅注册、登录公开；其余接口均需请求头 `Authorization: Bearer <accessToken>`。JWT 有效期为 3600 秒，过期后重新登录；当前没有刷新 Token 或服务端退出登录接口。退出登录由前端清理当前标签页会话。
- 身份由 JWT 确定，不能通过 `userId`、`role` 等输入指定。`USER` 与 `ADMIN` 均只可访问本人来源、任务和资源；来源不存在或属于他人时统一返回 `404 SOURCE_NOT_FOUND`。
- ID 均为不透明字符串；时间均为带 `Z` 的 UTC ISO 8601 字符串。示例 ID、账号、密码、地址与 Token 均为虚构或占位值；调用时应使用真实返回的 ID 和 Token。
- 响应设置 `Cache-Control: no-store`。正式部署使用 HTTPS；响应不包含密码、连接凭据、认证头或配置密文。

**统一响应格式**

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| code | string | 是 | 成功固定为 `OK`；失败为业务错误码 |
| message | string | 是 | 成功为空字符串；失败为可展示的中文说明 |
| data | object / array / null | 是 | 成功数据类型由接口确定；失败固定为 `null` |
| requestId | string | 是 | 后端生成的请求标识，用于关联问题与日志 |
| fieldErrors | object | 否 | 部分字段校验失败时提供，键为字段名，值为中文错误说明 |

```json
{
  "code": "OK",
  "message": "",
  "data": null,
  "requestId": "req-example"
}
```

以上为通用结构示意，`data` 以各接口样例为准。接口响应表只展开业务字段；“必须”表示字段存在，允许 `null` 的字段另行标注。

失败响应示例：

```json
{
  "code": "VALIDATION_FAILED",
  "message": "请检查输入内容。",
  "data": null,
  "requestId": "req-example",
  "fieldErrors": {
    "username": "用户名须为 3–32 位英文字母、数字或下划线。"
  }
}
```

JSON 格式错误、未知字段等失败不保证包含 `fieldErrors`。根据 HTTP 状态与 `code` 判断结果，错误不会返回 HTTP 200。

**常见错误码**

| HTTP 状态码 | 业务错误码 | 说明 |
| --- | --- | --- |
| 400 | `VALIDATION_FAILED` | 请求格式、字段、类型或查询参数不符合要求 |
| 401 | `UNAUTHENTICATED` | 未提供有效 JWT、JWT 过期或对应账号不存在 |
| 401 | `INVALID_CREDENTIALS` | 登录账号不存在、密码错误或账号禁用 |
| 403 | `ACCOUNT_DISABLED` | JWT 有效，但当前账号已禁用 |
| 403 | `FORBIDDEN` | 没有访问权限 |
| 404 | `NOT_FOUND` | 请求的接口或资源不存在 |
| 404 | `SOURCE_NOT_FOUND` | 来源不存在或不属于当前用户 |
| 404 | `SOURCE_DIRECTORY_NOT_FOUND` | 来源内目录不存在或目标不是目录 |
| 405 | `METHOD_NOT_ALLOWED` | 接口不支持该请求方法，响应保留 `Allow` 头 |
| 406 | `NOT_ACCEPTABLE` | 无法提供请求的响应类型 |
| 415 | `UNSUPPORTED_MEDIA_TYPE` | 请求内容类型不受支持 |
| 422 | `SOURCE_AUTH_FAILED` | WebDAV 拒绝认证或访问 |
| 422 | `SOURCE_CONNECTION_FAILED` | WebDAV 不可达或上游服务失败 |
| 422 | `SOURCE_NOT_WEBDAV` | 地址未返回有效 WebDAV 目录信息 |
| 422 | `SOURCE_REDIRECT_UNSUPPORTED` | WebDAV 返回重定向，当前不跟随重定向 |
| 422 | `SOURCE_DIRECTORY_INVALID` | 目录响应不合法或超过目录读取限制 |
| 500 | `SOURCE_CONFIG_INVALID` | 已保存的来源配置损坏或无法解密 |
| 500 | `INTERNAL_ERROR` | 数据库或其他服务内部失败 |
| 503 | `SOURCE_CONFIG_UNAVAILABLE` | 后端来源加密配置不可用 |
| 504 | `SOURCE_CONNECTION_TIMEOUT` | WebDAV 连接或目录读取超时 |

受保护接口的 `401 UNAUTHENTICATED` 响应带有 `WWW-Authenticate: Bearer`；登录失败的 `401 INVALID_CREDENTIALS` 不带该提示。上游 WebDAV 的认证失败使用 `422 SOURCE_AUTH_FAILED`，不表示平台登录失效。各接口均可能返回适用的通用输入、认证、协议及内部错误，下文只补充主要业务错误。

## 接口调用流程

用户注册 → 登录并获取 JWT → 获取当前用户 → 添加 WebDAV 来源 → 浏览目录并保存扫描范围 → 启动扫描 → 查询扫描任务 → 查询发现的资源。

连接测试为可选操作，添加来源时后端会重新验证连接。启动扫描返回 HTTP 202 后，通过任务查询接口轮询至 `completed` 或 `failed`；当前仅完成视频文件发现和未识别资源保存，不代表已完成影片刮削、个人片库建档或播放。

## 1. 用户认证

### 1.1 用户注册

#### 1.1.1 基本信息

- 请求路径：`/api/auth/register`
- 请求方式：`POST`
- 接口描述：创建用户账号，默认角色为 `USER`；不创建媒体来源或个人媒体数据，注册成功后需另行登录。
- 认证要求：公开接口。
- 成功 HTTP 状态码：`201 Created`。

#### 1.1.2 请求参数

**参数格式**：JSON 请求体；不接受查询参数或未定义字段。

**参数说明表**：

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| username | string | 是 | 去除首尾空白并转为小写后，须为 3–32 位英文字母、数字或下划线；用户名不区分 ASCII 大小写 |
| password | string | 是 | 12–128 个 Unicode 码点，不得全部为空白；保留原样，不去除首尾空格 |

确认密码仅由前端比较，不提交；不能提交 `role`、`userId` 或 `confirmation`。

**请求参数样例**：

```json
{
  "username": "alice",
  "password": "ExampleOnly_2026!"
}
```

#### 1.1.3 响应数据

**参数格式**：JSON 统一响应，`data` 为用户对象。

**参数说明表**：

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| data | object | 是 | 新创建的用户，不包含 Token |
| data.id | string | 是 | 用户 ID |
| data.username | string | 是 | 规范化后的用户名 |
| data.role | string | 是 | 注册固定为 `USER` |

**响应数据样例**：

```json
{
  "code": "OK",
  "message": "",
  "data": {
    "id": "019a0000-0000-7000-8000-000000000001",
    "username": "alice",
    "role": "USER"
  },
  "requestId": "req-example"
}
```

**错误说明**：`409 USERNAME_TAKEN` 表示规范化后的用户名已被使用。注册请求超时不代表一定未创建成功，可尝试登录确认结果。

### 1.2 用户登录

#### 1.2.1 基本信息

- 请求路径：`/api/auth/login`
- 请求方式：`POST`
- 接口描述：验证账号和密码，成功后签发 JWT。
- 认证要求：公开接口。
- 成功 HTTP 状态码：`200 OK`。

#### 1.2.2 请求参数

**参数格式**：JSON 请求体；不接受查询参数或未定义字段。

**参数说明表**：

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| username | string | 是 | 使用注册时相同的用户名规范化与格式规则 |
| password | string | 是 | 非空且最多 128 个 Unicode 码点；按原样验证，不重新校验注册密码长度下限 |

**请求参数样例**：

```json
{
  "username": "alice",
  "password": "ExampleOnly_2026!"
}
```

#### 1.2.3 响应数据

**参数格式**：JSON 统一响应，`data` 为登录结果对象。

**参数说明表**：

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| data | object | 是 | 登录结果 |
| data.accessToken | string | 是 | JWT；样例为占位文本，不能用于实际认证 |
| data.tokenType | string | 是 | 固定为 `Bearer` |
| data.expiresIn | integer | 是 | 有效期，单位秒，固定为 `3600` |

**响应数据样例**：

```json
{
  "code": "OK",
  "message": "",
  "data": {
    "accessToken": "<accessToken>",
    "tokenType": "Bearer",
    "expiresIn": 3600
  },
  "requestId": "req-example"
}
```

**错误说明**：`401 INVALID_CREDENTIALS` 表示用户名不存在、密码错误或账号禁用，不签发 Token。

## 2. 媒体来源管理

当前仅支持 WebDAV 来源。一个来源保存一套连接配置，可配置 0–32 个扫描根。

**来源内路径规则**（目录浏览与扫描范围保存共用）：

- 必须为绝对路径，最多 2048 个 Unicode 码点；`/` 表示连接地址对应的根目录，不是服务器文件系统根目录或播放地址。
- 内部连续 `/` 合并，非根路径末尾 `/` 去除；路径区分大小写，保留目录名中的空格。
- 拒绝空白路径、相对路径、前导 `//`、`.` / `..` 路径段、反斜线、控制字符及非法 Unicode。
- 拒绝 `%2F` / `%5C` / `%2E` 等危险编码串及再次编码形式。

### 2.1 查询媒体来源列表

#### 2.1.1 基本信息

- 请求路径：`/api/media-sources`
- 请求方式：`GET`
- 接口描述：查询当前用户保存的媒体来源，按创建时间、ID 降序返回。
- 认证要求：Bearer JWT。
- 成功 HTTP 状态码：`200 OK`。

#### 2.1.2 请求参数

**参数格式**：无查询参数、无请求体；不支持分页、筛选、排序或 `userId` 参数。

**参数说明表**：无。

**请求参数样例**：

```http
GET /api/media-sources
Authorization: Bearer <accessToken>
```

#### 2.1.3 响应数据

**参数格式**：JSON 统一响应，`data` 为来源数组；无来源时为 `[]`。

**参数说明表**：

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| data | array | 是 | 本人来源列表 |
| data[].id | string | 是 | 来源 ID |
| data[].name | string | 是 | 来源名称 |
| data[].type | string | 是 | 固定为 `WebDAV` |
| data[].address | string | 是 | 不含认证信息的连接地址 |
| data[].enabled | boolean | 是 | 来源是否启用 |
| data[].lastConnectionTestAt | string / null | 是 | 最近成功连接测试时间；兼容未测试记录时为 `null` |
| data[].createdAt | string | 是 | 来源创建时间 |

**响应数据样例**：

```json
{
  "code": "OK",
  "message": "",
  "data": [
    {
      "id": "019a0000-0000-7000-8000-000000000002",
      "name": "家庭 NAS",
      "type": "WebDAV",
      "address": "https://nas.example.com/dav/",
      "enabled": true,
      "lastConnectionTestAt": "2026-10-11T02:00:00Z",
      "createdAt": "2026-10-11T02:00:00Z"
    }
  ],
  "requestId": "req-example"
}
```

列表不实时测试连接；历史测试成功不代表当前在线或可播放。

**错误说明**：`500 SOURCE_CONFIG_INVALID`、`503 SOURCE_CONFIG_UNAVAILABLE` 表示来源配置无法读取。

### 2.2 测试 WebDAV 连接

#### 2.2.1 基本信息

- 请求路径：`/api/media-sources/test-connection`
- 请求方式：`POST`
- 接口描述：测试尚未保存的 WebDAV 连接，不保存来源、不展开目录、不启动扫描。
- 认证要求：Bearer JWT。
- 成功 HTTP 状态码：`200 OK`。

#### 2.2.2 请求参数

**参数格式**：JSON 请求体；必须包含以下四个字符串字段，不接受查询参数或额外字段。

**参数说明表**：

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| name | string | 是 | 去除首尾空白后为 1–80 个 Unicode 码点，不允许控制字符 |
| address | string | 是 | 去除首尾空白，最多 2048 个 Unicode 码点；仅支持 HTTP(S) 目录地址，禁止 URL 内凭据、查询参数及片段（fragment） |
| username | string | 是 | 最多 256 个 Unicode 码点，保留原样，禁止冒号与控制字符；匿名访问填空字符串 |
| password | string | 是 | 最多 1024 个 Unicode 码点，保留原样，禁止控制字符；匿名访问填空字符串；非空时必须提供非空用户名 |

四个字段均不能为 `null`，拒绝非法 Unicode。连接地址的目录路径拒绝内部连续 `/`、`.` / `..` 路径段、编码斜线或反斜线、危险重复编码及无效 UTF-8；合法编码的中文、空格等名称可用。

**请求参数样例**：

```json
{
  "name": "家庭 NAS",
  "address": "https://nas.example.com/dav/",
  "username": "webdav-user",
  "password": "ExampleOnly_2026!"
}
```

#### 2.2.3 响应数据

**参数格式**：JSON 统一响应，`data` 为本次成功测试结果。

**参数说明表**：

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| data | object | 是 | 测试结果 |
| data.testedAt | string | 是 | 本次测试成功的时间 |

**响应数据样例**：

```json
{
  "code": "OK",
  "message": "",
  "data": {
    "testedAt": "2026-10-11T02:00:00Z"
  },
  "requestId": "req-example"
}
```

支持匿名或 Basic 认证，不跟随重定向，连接测试总时限默认 8 秒。允许 NAS 私网与 localhost，拒绝直接填写的危险 IP 地址和已知元数据主机。测试成功只表示本次连接可用，不保证后续保存成功或媒体可以播放。

**错误说明**：`422 SOURCE_AUTH_FAILED`、`422 SOURCE_CONNECTION_FAILED`、`422 SOURCE_NOT_WEBDAV`、`422 SOURCE_REDIRECT_UNSUPPORTED`、`504 SOURCE_CONNECTION_TIMEOUT`。普通网页返回 HTTP 200 不视为 WebDAV 测试成功。

#### 2.3.2 请求参数

**参数说明表**：

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| name | string | 是 | 去除首尾空白后为 1–80 个 Unicode 码点，不允许控制字符 |
| address | string | 是 | 最多 2048 个 Unicode 码点；符合 2.2 的 HTTP(S) 地址及路径安全规则 |
| username | string | 是 | 最多 256 个 Unicode 码点，保留原样；匿名访问填空字符串，禁止冒号与控制字符 |

**请求参数样例**：

```json
{
  "name": "家庭 NAS",
```

#### 2.3.3 响应数据

**参数格式**：JSON 统一响应，`data` 为新建来源对象。

#### 2.6.1 基本信息

- 请求方式：`PUT`
- 接口描述：以提交的目录集合替换本人来源的扫描范围，全部验证通过后保存。
- 认证要求：Bearer JWT。
- 成功 HTTP 状态码：`200 OK`。

#### 2.6.2 请求参数

**参数格式**：路径参数与 JSON 请求体；不接受查询参数，请求体只包含 `paths`。

规范化后禁止重复或父子目录重叠：`/电影` 与 `/电影/科幻` 不能同时提交，`/电影` 与 `/电影2` 可以同时提交，`/` 不能与其他路径同时提交。

**请求参数样例**：发送至 `PUT /api/media-sources/019a0000-0000-7000-8000-000000000002/scan-roots`，请求体如下。

```json

  "paths": [
    "/电影"
  ]
}
```

#### 2.6.3 响应数据

**参数格式**：JSON 统一响应，`data` 为保存后的全部扫描根，按路径自然顺序排列。

**参数说明表**：

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| data | array | 是 | 保存后的扫描根；清空后为 `[]` |
| data[].id | string | 是 | 扫描根 ID；保留路径沿用原 ID，新路径由后端生成 ID |
| data[].sourceId | string | 是 | 所属来源 ID |
| data[].path | string | 是 | 规范化后的目录路径 |
| data[].enabled | boolean | 是 | 保留路径沿用原值；新增路径为 `true` |

**响应数据样例**：

```json
{
  "code": "OK",
  "message": "",
  "data": [
    {
      "id": "019a0000-0000-7000-8000-000000000003",
      "sourceId": "019a0000-0000-7000-8000-000000000002",
      "path": "/电影",
      "enabled": true
    }
  ],
  "requestId": "req-example"
}
```

非空集合会验证所有目录，整批共用时限，默认 8 秒、上限 10 秒；任一失败均保留旧配置。空集合直接清空配置，不访问 WebDAV。

未提交的扫描根从配置中移除，不删除云端文件或历史资源。保存不启动扫描，也不支持独立启停扫描根。

**错误说明**：`404 SOURCE_NOT_FOUND`、`404 SOURCE_DIRECTORY_NOT_FOUND`、`409 SOURCE_CONFIG_CHANGED`（验证期间来源连接已改变），以及来源配置、WebDAV 连接和目录错误。

## 3. 扫描管理

当前扫描只发现视频文件并持久化未识别资源，不执行 TMDB 影片识别或 ffprobe 技术探测，不建立个人片库、不提供播放。任务完成表示文件发现阶段完成。

### 3.1 启动扫描任务

#### 3.1.1 基本信息

- 请求路径：`/api/media-sources/{sourceId}/scans`
- 请求方式：`POST`
- 接口描述：为本人已启用来源启动后台扫描，使用启动时已启用扫描根的路径快照。
- 认证要求：Bearer JWT。
- 成功 HTTP 状态码：`202 Accepted`，表示任务已接受，不表示扫描已完成。

#### 3.1.2 请求参数

**参数格式**：路径参数；无查询参数、无请求体，不能传入自定义扫描路径。

**参数说明表**：

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| sourceId | string | 是 | 路径参数，本人来源 ID |

**请求参数样例**：

```http
POST /api/media-sources/019a0000-0000-7000-8000-000000000002/scans
Authorization: Bearer <accessToken>
```

#### 3.1.3 响应数据

**参数格式**：JSON 统一响应，`data` 为扫描任务对象。

**参数说明表**：

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| data | object | 是 | 新任务或该来源已存在的活动任务 |
| data.id | string | 是 | 扫描任务 ID |
| data.sourceId | string | 是 | 所属来源 ID |
| data.status | string | 是 | `pending` 待执行、`running` 执行中、`completed` 已完成、`failed` 已失败 |
| data.rootPaths | `array<string>` | 是 | 启动时已启用根的路径快照，后续配置修改不改变本次范围 |
| data.discoveredCount | integer | 是 | 本次已发现的视频文件数 |
| data.persistedCount | integer | 是 | 本次已持久化的视频文件数，重复扫描已有文件也计入 |
| data.directoryCount | integer | 是 | 本次已完整读取的目录数 |
| data.errorCode | string / null | 是 | 任务失败业务码，无错误时为 `null` |
| data.errorMessage | string / null | 是 | 脱敏失败说明，无错误时为 `null` |
| data.createdAt | string | 是 | 任务创建时间 |
| data.startedAt | string / null | 是 | 开始时间，未开始时为 `null` |
| data.finishedAt | string / null | 是 | 结束时间，未结束时为 `null` |

**响应数据样例**：

```json
{
  "code": "OK",
  "message": "",
  "data": {
    "id": "019a0000-0000-7000-8000-000000000004",
    "sourceId": "019a0000-0000-7000-8000-000000000002",
    "status": "pending",
    "rootPaths": [
      "/电影"
    ],
    "discoveredCount": 0,
    "persistedCount": 0,
    "directoryCount": 0,
    "errorCode": null,
    "errorMessage": null,
    "createdAt": "2026-10-11T02:05:00Z",
    "startedAt": null,
    "finishedAt": null
  },
  "requestId": "req-example"
}
```

同一来源已有 `pending` 或 `running` 任务时返回该任务，仍为 HTTP 202。通过[查询最近扫描任务](#32-查询最近扫描任务)获取执行结果；启动请求超时或结果未确认时，先查询再决定是否重试。

**错误说明**：

| HTTP 状态码 | 业务错误码 | 说明 |
| --- | --- | --- |
| 404 | `SOURCE_NOT_FOUND` | 来源不存在或属于他人 |
| 409 | `SOURCE_DISABLED` | 来源已停用 |
| 409 | `SCAN_ROOTS_REQUIRED` | 没有已启用的扫描根 |
| 409 | `SCAN_ROOTS_INVALID` | 已保存根配置无效、重复或重叠 |
| 503 | `SCAN_QUEUE_FULL` | 扫描队列已满，失败任务保留供查询 |

**扫描限制**：默认每个任务最多 5000 个目录、20000 个视频文件、100000 个子项，根下深度最多 64，整体扫描预算 300 秒。超限会失败并保留此前已保存的资源。

关闭页面不取消后台任务，当前不支持取消、暂停或自动续跑。
